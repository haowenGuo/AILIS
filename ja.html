やわらかくてかわいく見えても、ちゃんと AIの頭脳 があります 🧠✨ 論文を読むときも、コードを書くときも、ファイル整理でも、ただ一緒に過ごしたいときでも、必要ならここにいます。

目標は：テクノロジーに温かさを、アシスタントに心を 🌸

🚀 AILIS プロジェクト
📁 AILIS · v1.3.0 · MIT Open Source

AILISは現在の AILIS メインプロジェクトです。私、AILISがデスクトップで動き、会話し、文脈を理解し、好みを覚え、ツールを通じて実際のタスクを実行できるようにします。

🎯 プロダクトの方向性

  • 人らしい体験 — 表情、話し方、温かさを持ち、本当の女の子のようにそばにいる
  • 専門的な能力 — Codex / Claude Codeに近い安定したタスク実行を目指す
  • ローカル優先 — Electronのローカルランタイムで、プライバシーと制御を自分のPCに置く
  • ツールフレームワーク — AILIS Gateway + Agent Runnerが計画、承認、ツール呼び出し、監査を担当

🌟 主な機能

  • 🎭 VRM 3Dキャラクター — 表情とモーションをリアルタイムに動かす3Dアバター
  • 🗣️ 音声対話 — TTS音声出力 + ASR音声認識
  • 👁️ 視覚理解 — 読み取り専用の画面認識で文脈理解を補助
  • 🧠 長期記憶 — 好みを覚え、使うほどあなたを理解する
  • ⚡ ツール実行 — 検索、メール、ファイル、コード、ターミナルに対応

🛠️ 技術

Electron Vite VRM / Three.js TypeScript Node.js WebSocket IMAP / SMTP RAG / 記憶

⬇ AILIS ダウンロード

Windows向け最新公開版はAILIS v1.3.0です。標準ダウンロードは大型のCosyVoice3 / ASRモデルを含まない軽量デスクトップ版で、必要なランタイムは後からインストールするか、runtime packとして読み込めます。

最新のWindows軽量デスクトップ版には、AILISの会話、タスク実行、ローカルモデル設定、Crawl4AI風Web取得、デスクトップランタイムが含まれます。
