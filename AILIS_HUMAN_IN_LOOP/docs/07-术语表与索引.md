# 07｜术语表与索引

## 1. 核心术语

| 术语 | 在 AILIS 中的准确含义 |
| --- | --- |
| AILIS Persona | 用户面对的统一人格、关系和具身表达，不是工具执行器 |
| Persona Surface | 面向 UI/TTS/VRM 的规范化可见结果 |
| System TaskAgent | 唯一的系统任务执行代理，管理计划、工具、证据与完成 |
| Harness | TaskAgent 的生命周期、session、in-flight、持久化和结果包外壳 |
| Agent Runner | 模型决策—工具—观察—恢复—完成的多轮执行循环 |
| Gateway | Agent 与所有真实工具/服务之间的统一控制边界 |
| Runtime | 经权限允许后实际执行文件、进程、MCP、上下文等能力 |
| Tool Contract | 工具 id、schema、风险、输出和用户 experience 的契约 |
| Platform Adapter | 将桌面、Hosted、OS 差异收敛为统一能力 |
| MCP | Model Context Protocol；接入外部工具服务器的标准通道 |
| Observation | 工具返回给 Agent 的规范化观察 |
| Artifact | 可持久引用的文件、图片、长输出或结构化产物 |
| Evidence | 能支持最终声明且可追溯的来源/产物引用 |
| Exact Answer | 对字段、格式和证据粒度有严格要求的回答模式 |
| ContextManager | 管理模型工作历史、预算、压缩、配对和 checkpoint |
| Context Compiler | 将多类记忆按 section/budget 编译成 MemoryContext |
| Model Input Builder | 把 memory、conversation、task、tool items 变成模型输入 |
| Curated Memory | 经筛选整理、可用于人格连续性的长期记忆 |
| Raw Memory Ledger | 追加式原始运行/记忆账本，用于审计与重放 |
| Visible Conversation | 用户和 Persona 实际看见的对话，不等于全部内部上下文 |
| Checkpoint | 可恢复 task/context 状态的结构化快照 |
| Persona Renderer | 内部结果到安全自然用户表达和具身 cue 的转换器 |
| SpeechProvider | server/CosyVoice3/Native TTS 候选的选择和播放编排 |
| Native TTS | Chrome Web Speech `speechSynthesis`，声音来自终端浏览器 |
| Audio-driven lip sync | 从音频能量/时钟驱动 VRM 嘴形 |
| Fallback lip sync | 无 PCM 时用 utterance 生命周期/程序脉冲估算嘴形 |
| VRM | 3D 人形角色模型格式 |
| VRMA | VRM Animation 动作格式 |
| Hosted Runtime | 服务器上的 AILIS Agent/Memory/Tool 核心，为网页提供 API/SSE |
| Electron preload | 在隔离渲染进程与 Node 主进程之间暴露白名单能力 |
| Permission Profile | 当前运行允许的读、写、执行、网络等权限边界 |
| Approval | 用户针对具体高风险动作给出的显式授权 |
| Dry-run | 只展示/验证计划，不产生真实副作用 |
| Context budget | 模型输入可使用的 token/字符预算及分配 |
| Semantic compaction | 保留任务连续性和引用的语义压缩 |
| Output store | 保存过大工具输出并允许后续查询的存储 |
| Affinity | Persona 与用户关系阶段/分值的整理状态 |

## 5. 搜索方法

在正式仓库根目录用 ripgrep：

```powershell
rg -n "AILISSystemTaskAgentHarness|buildTaskResultPacket" electron tests
rg -n "renderPersonaSurfaceGateway|speechText|lipSync" electron src tests
rg -n "ContextManager|semanticCompact|toCheckpoint" electron tests
rg -n "needs_approval|permissionProfile|evidenceRefs" electron tests
rg -n "speechSynthesis|voiceschanged|NativeSpeechSynthesisCandidate" src tests
```

先搜符号定义，再搜全部调用方，再搜测试断言。大文件不要只依赖 IDE outline：
逐行讲解页顶部已列出静态识别的 dependencies 和主要 symbols。

## 7. 掌控系统时最值得记住的十句话

1. Persona 是唯一面对用户的人格。
2. TaskAgent 是唯一负责工作的系统代理。
3. 模型做语义决策，代码守确定性边界。
4. Memory、visible history、task、evidence 必须分通道。
5. Raw ledger 可审计，但不能原样灌进 prompt。
6. 工具成功不等于证据充分。
7. 审批必须绑定具体动作，不能由模型自批。
8. 压缩必须保住任务状态、引用和 call/output 配对。
9. Native Chrome TTS 与音频 PCM 驱动口型不是同一种同步能力。
10. 一项修改只有在目标测试、真实链路、构建和部署版本都验证后才算完成。
