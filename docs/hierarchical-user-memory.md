# 层级用户记忆

AILIS 1.5.0 将层级用户记忆作为正式能力接入现有 Agent 运行时。它不替换当前会话上下文，而是在会话发生语义压缩后，保存可追溯的摘要节点，并按层级归并较早材料。

## 工作方式

1. 正常会话仍沿用原有上下文、工具和压缩流程。
2. 每次有效的会话压缩会生成一个第 0 层摘要，并保留来源会话与节点身份。
3. 同层节点达到归并阈值后，模型将它们归并为更高层的用户理解节点。
4. 当前请求只注入不重叠的活跃节点；被覆盖的原始节点继续留在本地归档中。
5. 归并在后台执行，不阻塞当前任务；失败或不完整的模型输出不会消耗源节点。

## 数据边界

- 层级记忆按用户/租户隔离。
- 历史数据不会被自动批量回填；1.5.0 从新发生的有效压缩开始建立层级。
- 原始节点和归并节点都保留本地审计信息，清空活跃视图不等于安全擦除磁盘历史。
- 当前注入预算只控制展示给模型的预览，不替换完整归档材料。
- 默认归并阈值沿用 512K 会话窗口的 hard 阈值，即约 460,800 个估算输入 token；实际会话阈值优先。

## 验证边界

正式发布前已完成固定记忆门禁：20/20 trials 完成，baseline 通过 2 题，candidate 通过 3 题，没有整题 pass-to-fail 回退；记忆相关单元测试 49/49 通过，并完成真实模型的修正、归并、重启恢复和租户隔离 canary。

这不是长期主观记忆质量的证明。已知的 KV 长连接/存活性子检查在 candidate 中退化，已由本版本发布审批明确接受；后续应单独修复和复验，不应把它描述为全绿结果。
