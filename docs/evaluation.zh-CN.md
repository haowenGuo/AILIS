## 执行效率

**分数、模型调用、Token、缓存和时延分别呈现，不合成一个总分。**缓存率采用 `Σ缓存输入 / Σ输入`，不是逐题百分比的平均值，也不是理论前缀可复用率。下表 M = 1,000,000 Token，显示值经过四舍五入；精确整数见 [JSON](evaluation/20260907-snapshot.json)。

| :--- | ---: | ---: |

这里以粗体突出 AILIS 列，不表示这些效率指标最优。AILIS 用量包含两题未决已发生的开销，但不含所有废弃尝试。Codex 除以 5 是等量资源折算，不是挑选最好的一轮。两边时延均取 trial 开始到结束；机器、并发、时限、准备/判分和基础设施不同，观测到的 3.46 倍差距不是纯 Harness 开销。

Codex 存档 cost 为 445 次合计 $241.45，不是核对过的发票。AILIS 没有可对应的账单和历史结算单价，因此费用保留“—”，不把 Token 直接编造成实付金额。

## Harness 优化：同题前后对照

下面是 9 月 3 日输出修复前与 9 月 4 日输出修复后，经双边有效性审计的 **84 道共同题**，不是与 Codex 的对比。

| 指标 · 相同 84 题 | 输出修复后 | 输出修复前 |
| :--- | ---: | ---: |
| 通过率 | **75.00%** | 59.52% |
| 通过题数 | **63 / 84** | 50 / 84 |
| 模型请求 | **3,854** | 4,816 |
| 结果变化 | **17 题改善，4 题退步** | 共同题净增 13 通过 |

模型请求减少约 20%，但输入 Token 增加约 32%，累计 Agent 时间仅降低约 1.9%。并发、时限与基础设施也有变化，不能将全部变化单独归因于取消裁剪。

### LongMemEval-S 与 LoCoMo：记忆检索和问答

2026-08-05 的基线记录使用 **BM25 phrase v2 + soft session-diversity MMR（penalty 0.2），Top-8 检索**。检索阶段是本地确定性流程，不使用稠密检索或检索时的 LLM 查询规划器；答案生成和评分是检索之外的环节。

| 指标 | LongMemEval-S | LoCoMo |
| :--- | ---: | ---: |
| 已完成题数 | 500 / 500 | 1,986 / 1,986 |
| 答案成绩 | 问答准确率 71.60% · 358 题正确 | token-F1 24.69 · 0–100 标度 |
| Session recall @8 | 93.53% | 89.67% |
| Turn recall @8 | 83.31% | 71.75% |
| 端到端 p50 | 18.6s | 12.72s |

LongMemEval-S 记录的 Reader / Judge 为 **Luna / Luna medium**，生成和 Judge 失败均为 0。评分采用官方 LongMemEval 原始提示词及二值汇总，但这是本地成绩，不是官方榜单提交。LoCoMo 的历史汇总未注明 Reader 模型与推理档位，因此不推定它使用当前模型配置。LoCoMo 的 token-F1 衡量答案重合程度，**24.69 不代表通过了 24.69% 的题目**。协议与成绩来源：[历史记忆基线](https://github.com/haowenGuo/AILIS/blob/659bf61f2b340d2313b3bae386704265c8d2bba2/docs/ailis-memory-bm25-mmr-baseline.md)。

- 运行：`ailis-terminal89-output-integrity-parallel20-luna-max-20260904-v1`。
- 源码：冻结 `07c1e85` 加七个工具输出完整性文件；9 月 5 日独立连接修复单题未混入。
- 配置：Luna Max；并发 20→10，后期恢复 3/1；外层 3000s，内层仍有原题预算。保留已有效的通过/失败，基础设施恢复另记，不能视为与官方同条件的干净 pass@1。
- 原始 progress 保持 65 通过 / 23 失败 / 1 未决。审计发现 `bn-fit-modify` 的 verifier 依赖下载遇到 TLS 错误、测试未启动，将其从能力分母排除，未修改原奖励或补记通过。

- 官方存档不是本地 445 次实跑轨迹，也不是实时榜单。独立本地 Codex 逐题证据覆盖 16 道不同题（9 月 7 题、8 月 10 道有效题，caffe 重叠）；其余 73 题的对应奖励与时延未知，不能补造配对结果。
