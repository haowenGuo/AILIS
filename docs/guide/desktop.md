# 使用桌面应用

AILIS 将聊天、工具执行和角色交互放在同一个桌面应用中。完成文本对话需要 Electron 应用、已安装的项目依赖，以及可用的模型服务；语音、视觉和扩展工具按需配置。

## 启动

在要运行的仓库根目录打开终端。项目使用 pnpm，版本由 package.json 中的 packageManager 固定为 10.33.0。

```powershell
pnpm install --frozen-lockfile
pnpm desktop:dev
```

开发模式同时启动 Vite 与 Electron。Vite 使用 5173 端口，并监听 0.0.0.0；请在受信网络使用。需要用生产前端启动时执行：

```powershell
pnpm desktop:start
```

这个命令先构建桌面页面，再启动当前目录的 Electron。依赖安装会下载文件；应用启动会读取并保存设置。模型请求可能产生费用。

## 五个桌面界面

| 界面 | 用途 |
| --- | --- |
| 桌宠 | 在桌面呈现角色、对话气泡、语音和动作 |
| 聊天窗口 | 输入消息、提交附件、阅读回答和过程信息 |
| 控制面板 | 设置显示、人物、任务权限、模型、邮箱与语音 |
| Agent Lab | 选择运行记录，查看轮次、上下文和工具；发起调试运行 |
| 区域选择 | 为屏幕观察选择区域 |

窗口由 Electron 主进程创建。聊天窗口与桌宠通过事件交换输入和显示状态，设置通过主进程保存。

## 完成第一次文本任务

1. 打开控制面板的“模型 API”，设置服务类型、地址、模型和凭据。
2. 保存后使用模型连接检查；收到响应后，在聊天窗口发送一条简短消息。
3. 准备一个专用测试文件夹，再要求 AILIS 读取其中的文件并指出来源。
4. 需要产生文件时，在请求中明确输出目录、文件名和验收要求。

例如：“读取这个测试目录中的 CSV，统计记录数量，将结果保存为同目录的 count.txt。”文件的实际存在与内容是任务的验收对象，聊天中的文字是结果说明。

权限不足时，根据应用返回的审批或失败信息处理。中断任务只终止后续执行，不自动撤销已经发送的消息或写入的文件。

## 使用附件

文件选择和路径描述通过桌面 IPC 完成。聊天服务将附件信息提交给 Gateway，图片还可以成为模型输入中的图像内容。Office、PDF、CSV 等文件由对应工具适配器处理。

附件能否读取或编辑取决于格式、适配器依赖和模型／工具配置。处理结果带有文件或工件引用时，可以继续要求查询、导出或验证。

## 启用语音与屏幕观察

在“语音与麦克风”中选择识别模式、设备及合成方式。本地 ASR、CosyVoice3 需要相应运行组件；先准备组件，再分别验证转写和合成。屏幕观察使用截图和视觉能力，独立视觉模型在控制面板中配置。

更完整的说明见[配置](configuration.md)与[媒体系统](../design/media.md)。

## 使用 Agent Lab

Lab 提供 Session 输入、步数上限、审批选项、逐轮启动、下一轮、完整流程和中断操作。选择已有记录可以查看分析；点击运行按钮会发起任务。

当前“逐轮调试启动”传入 step mode，此时构造请求会将 dryRun 设为 false，即使界面复选框仍勾选。请只在独立测试目录执行调试，并明确工具权限。Lab 的逐轮控制是调试机制，不是只读浏览模式。

## 获取帮助

连接问题先检查模型配置；附件问题检查实际路径和工具返回；语音问题分别检查转写、合成、播放。需要分析一次执行时保留 Session、run ID、时间和错误码，参见[运行观测](../engineering/measurement.md)。
