## 当前可以验证的交互

- 运行中：可展开执行记录，显示实际工具调用、耗时、公开进度和允许展示的流式文本；不展示隐藏推理。
- 追加：发送不再等于停止。运行中只支持文字；按同一会话、同一任务定位，消息旁仅显示“待处理”等异常/未完成状态；“已带入模型请求”在任务详情中可核对，不等于模型已完成要求。
- 成果：受控 `write` / `apply_patch` 保存写入前后快照、哈希、只读差异和行数；提供文件所在目录入口。原有修改不归入新增成果；同一文件多次写入保留各自记录。
- 图片：输入图片、工具返回的 PNG/JPEG/WebP、受控写入的这些图片，保存本地资源后在聊天中显示，可放大。不会自动加载远程图片或执行 SVG/HTML。
- 失败 / 停止：错误长期保留，工具原始错误可查看；保留已产生的文字和文件修改。停止先显示“正在停止…”，等待后台确认，拒绝后续工具分发；仅处理该任务拥有的命令进程。不能确认退出时显示“需要确认”，需人工检查确认后解锁。
- 长输出：工具返回与原始输出存档分开。宿主验证存档所属任务后分页读取，不把截断后的工具预览称为完整命令输出。
- 刷新：聊天窗关闭或重新加载不拥有后台任务生命周期；能恢复任务状态和待处理追加。宿主重启不自动重放可能有副作用的任务。
- 新对话 / 历史：原“清空会话”改为“新对话”，创建独立 Session，不删除旧记录。会话菜单可切换回历史会话；运行中、状态待确认或存储异常时不允许切换。多个窗口跟随同一宿主选择，旧窗口不能把消息误投给新会话。
- 主动搭话：沿用已有用户开关、触发逻辑和提示词，但实际回复进入同一宿主任务链；用户任务运行时不插入主动任务。桌宠和聊天窗读取同一条最终记录，历史回放不重复播报，默认主动搭话仍关闭。
- 阅读不中断：选中运行记录中的文字时，保留该段 DOM，避免流式刷新清掉选择；宿主状态和输入控制仍更新，取消选择后显示最新记录。展开的过程和已打开的查看窗口不被流式刷新关闭。
- 写盘故障：流式定时刷盘、工具证据写入失败有明确错误提示，关闭该会话的后续执行入口，不伪报完成，也不允许用“确认旧进程退出”绕过存储故障。修复存储后需重启并检查恢复状态；已产生的文件修改不撤销。

## 代码边界

`electron/ailis-task-interaction.cjs` 是主进程的交互记录与回执控制器。每会话 JSONL 顺序记录，用户正文与接受回执在同一次持久化中提交；先写入并同步磁盘再通知界面。沿用已有会话互斥机制，不新建数据库或 Agent。

流式日志只追加新增文字片段，重放时还原全文，避免每次刷新重复写入全部历史文本。丢弃某个旧响应流只影响那个流；迟到的旧流片段不会重新显示。存储故障提示是明确标记的内存故障状态，不冒充已成功写盘的终态记录。

`electron/ailis-gateway.cjs` 仍调用原本的统一 Agent、输入门控和输出门控。增加的是精确任务定位、生命周期事件关联，以及执行宿主的成果记录钩子，不是新工具编排器。输入追加继续使用 Runner 的现有待输入队列；在实际模型请求边界记录“已带入”。停止不会将一个失效 runId 自动替换成另一个正在运行的任务。

`src/task-interaction-client.js` 统一聊天窗、桌宠和语音入口的发送回执规则；传输状态未知时查询同一个消息 ID，重试不生成重复执行。图片正文不塞进 sessionStorage。

`src/task-interaction-view.js` 只读取记录和资源。默认单列会话、可展开过程、独立发送与停止按钮，按需打开只读成果预览；常驻横幅只用于阻断性的存储异常，不用于每个正常任务。`src/task-interaction.css` 为其样式。

桌宠/TTS 在预览中订阅宿主最终可见回答。TTS 播放失败不会决定任务完成状态；历史回放不自动播报。预览中禁用旧聊天存储写入和旧后台回答订阅，系统错误通知仍独立保留，避免同一回答出现两次。状态待确认时也保持忙碌并停止主动调度。

旧聊天记录只读导入展示。模型记忆仍由现有 Session context store 管理；界面日志不会变成另一份模型语义历史。

## 建议的人工体验顺序

1. 先发送普通任务，例如“在当前工作目录创建 demo.js，计算 1 到 100 的和，再运行并告诉我结果”；观察等待模型、执行工具、最终回答是否连续显示。
2. 运行尚未结束时追加文字，检查消息旁先出现“待处理”，带入请求后标签消失；可以从过程内或回答下方的“任务详情”图标核对完整回执。如果上一轮刚好结束，应形成独立的新一轮，而不是偷偷把追加投给别的任务。
3. 用文件编辑工具产生的修改，查看本次成果、只读差异和所在目录；上传一张图片，检查缩略图与放大查看。普通命令的任意文件写入不保证出现变更卡片，见下方边界。
4. 让它执行一个你愿意中断的短时任务，点击独立停止按钮；应先等待后台确认，已有修改不被撤销。
5. 结束后从会话菜单点“新对话”，再进“历史会话”切回来，检查记录仍在；也可关闭聊天窗再打开检查恢复。

遇到异常请保留原话、操作步骤和截图。独立测试日志在 `tmp/task-interaction-preview-logs`；任务证据在 `tmp/task-interaction-profile/state/task-interaction`。这些日志可能包含你的任务正文，不要不加检查就公开上传。

接续状态与测试记录也保存在 `.codex-memory/current.md`，避免把一次旧结果当作最终结果。
