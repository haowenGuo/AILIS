# AILIS v1.4.0 发布素材包

## 统一定位

AILIS 是一个开源桌面 AI 伙伴。她拥有可见的 3D 角色、语音和长期记忆，也能理解用户授权的屏幕与文件上下文，通过搜索、代码、文件和电脑工具完成真实任务。

本次发布只讲一个工作流：

> 把正在处理的屏幕、文件或问题交给 AILIS，她会理解上下文、调用工具完成任务，并把重要偏好留到下一次协作中。

统一链接：

- GitHub: https://github.com/haowenGuo/AILIS
- Release: https://github.com/haowenGuo/AILIS/releases/tag/v1.4.0
- Web: https://101.133.239.56/Test/
- Evaluation: https://github.com/haowenGuo/AILIS/blob/main/docs/evaluation.md

## 发布事实

- Windows 桌面端，MIT 开源。
- 具备 VRM 角色、文字和语音交互、长期记忆、屏幕与文件上下文、通用工具执行。
- GAIA public validation: AILIS-Luna 72.12%，同协议 Codex-Luna 64.85%。
- Terminal-Bench 2.1: AILIS A7 67.42% pass@1，官方 Codex-Luna Max 75.73% ± 1.32%。
- 不把 Web 演示描述成完整桌面版。电脑操作、本地文件和完整 TaskAgent 能力以 Windows 桌面版为准。

## 掘金

标题：

> 从 Persona 到 TaskAgent：AILIS 如何把桌面角色接入可评测的通用 Agent Harness

摘要：

> AILIS 将角色交互与任务执行分层：Persona 负责持续对话和表达，TaskAgent 负责 canonical history、工具调用、上下文压缩、恢复与审计。本文用 GAIA 和 Terminal-Bench 的同模型数据解释这套 Harness 已经解决了什么，以及缓存率和长任务稳定性仍然卡在哪里。

技术重点：

- 原生工具调用与结构化结果回填。
- 长上下文保留和接近窗口边界时的 compaction。
- 工具调用、审批、审计和错误恢复。
- 固定模型下 AILIS 与 Codex 的端到端对照。
- 失败版本如何因为局部优化造成全局回退。
