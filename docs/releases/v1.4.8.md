# AILIS v1.4.8

本版修复 AILIS 服务器模式下图片工具的认证与能力判断，并补齐模型连接诊断。

## 更新内容

- 图片描述工具支持 AILIS 托管会话认证，不再错误要求用户填写个人 API Key；不会转发配置中残留的个人 Key。
- 不再根据 `ailis-cloud` 这个模型别名推断“不支持视觉”。服务器明确声明不支持时给出错误，未声明时正常提交图片并保留实际服务端结果。
- AILIS 服务器模式不再使用界面已隐藏的旧辅助视觉模型配置；直接 API 模式的设置仍保留。
- 增加模型请求阶段、耗时及底层错误原因日志。日志不进入模型上下文，不记录请求正文和认证凭据。
- 保留当前桌面版的工具补丁处理整理及本地模型桥重试生命周期修复。

## 平台与验收

Windows x64、Linux x64、macOS Intel x64、macOS Apple Silicon arm64 从同一源码提交原生构建。
发布附件包含逐平台源码身份、安装包 SHA256、冷环境工具执行及离线 ASR 验收证据。
Windows 另执行实际 NSIS 安装、全新用户环境服务器对话、启动及卸载检查。

视觉回归测试使用模拟服务端，验证认证、能力声明及完整图片传输；不把它表述为线上模型识图质量评测。
完整 Whisper Small 与私有 CPU 推理环境继续随包提供；模型服务和远端 TTS 仍需联网。
Windows 未作可信发布者签名；macOS 为 ad-hoc 签名，未作 Apple 公证，要求 macOS 14 或以上。
Linux 验收覆盖原生构建与 TAR 重定位，不等同于所有发行版桌面、麦克风或 GUI 权限验证。

本次仅发布桌面安装包，不部署模型服务器、迁移数据库或启用支付；不包含用户配置、聊天记录、凭据及未发布沙箱实验。
v1.4.7 安装包保留，可用于回退。
