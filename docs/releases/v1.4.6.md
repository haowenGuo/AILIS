# AILIS v1.4.6 — 任务反馈与执行中修正

本版以已发布的 v1.4.4 跨平台版本为基础，合入经过本地体验调整的任务交互功能。保留原有聊天界面，不引入另一套操作面板。

## 更新内容

- 模型在执行前和执行中产生的可见进度会及时显示；它不是工具日志的改写，也不额外请求模型生成进度。
- 运行中可追加文字。已接收与已带入下一次模型请求分开记录，不强行中断正在执行的命令。
- 原始工具信息默认折叠，仍可检查完整结果；任务计划在模型调用 update_plan 时展示，不自动编造计划。
- 受控文件改动可查看证据。保留 v1.4.4 的补丁预检查、原子替换和失败恢复逻辑，整次补丁成功后才记录成果。
- 保留 AILIS 自身人设，移除先前继承的 Codex 身份和通用人设覆盖。
- 保留工作目录初始化、权限边界、跨平台路径处理、错误信息保真，以及独立的语音运行时。

## 安装与范围

目标为 Windows x64、Linux x64、macOS Intel x64 和 Apple Silicon arm64。完整 Whisper Small、私有 Python 与 CPU 推理依赖随包提供；没有可选组件安装页。微软 TTS 和模型服务仍需网络。

Windows 包未作发布者签名；macOS 使用 ad-hoc 签名，未作 Developer ID 签名或 Apple 公证。不支持承诺所有硬件、旧操作系统或所有音频驱动。

## 发布验收

仅在同一提交的四个平台原生构建、源码/前端身份核对、隔离配置下 EXEC/命令行/补丁执行、离线 ASR，以及 Windows 安装后验收全部通过后发布。
最终 Release 随附各平台校验和、源码提交和验收报告。合成语音识别的可用性不代表所有真实录音的准确率；真实麦克风、在线模型服务和系统权限体验需用户实测。

旧 v1.4.4 和历史 v1.4.5 草稿保留，本版不会覆盖旧标签或资产。
