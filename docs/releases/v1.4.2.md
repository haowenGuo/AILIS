# AILIS v1.4.2

## Desktop Experience

- Redesigned chat window and control panel with more compact layouts, clearer
  controls, message copying, conversation search, and settings search.
- New avatar quick-controls panel for chat, settings, language, voice mode,
  and character scale, with persisted selections and visible save failures.
- Improved draft handling, conversation scrolling, window sizing, and dialogue
  bubble placement without shrinking the character canvas during dragging.
- Updated Chinese, English, Japanese and Korean interface text.

## Voice

- Added Ordinary Voice Mode using AILIS's online TTS service. An internet
  connection is required; it is not an offline engine or a service SLA.
- Local ASR now reads the configured voice-runtime directory, verifies native
  Python dependencies asynchronously, and no longer trusts `python --version`
  or stale readiness flags as proof that recognition works.
- Improved ASR worker restart, pending-request cleanup and dependency errors.
- Standalone ASR preparation requires a Transformers release containing the
  upstream Whisper silence-detection compatibility fix.

## Agent And Packaging

- Includes the current unified Agent/session context, tool-output integrity,
  Codex connection lifecycle and model configuration persistence improvements.
- Retains the latest main-branch runtime cleanup and production dependency
  closure instead of restoring the old monolithic package contents.
- Adds release regression coverage for the new desktop and ASR changes, plus
  hidden Electron UI checks and clean Windows installation checks.

## Downloads And Requirements

- `AILIS-Setup-1.4.2-win-x64.exe`: Windows x64 installer with installation-path selection.
- `AILIS-Portable-1.4.2-win-x64.exe`: Windows x64 portable edition.
- `SHA256SUMS.txt`: integrity hashes for the release artifacts.

This is the lightweight AILIS edition, without Unity/AIGAME. Large Python,
CosyVoice3, offline ASR and local model runtimes are not bundled. Offline voice
requires separately installed runtime/model components; the developer's local
environment is not shipped to users. Existing user settings and memory remain
in the local application data directory, separate from program files.

The Windows binaries are not Authenticode-signed; Windows may show a publisher
or SmartScreen warning. AILIS tool execution can access local resources under
the configured permissions; this release does not claim OS-level sandbox
isolation. Recognition quality depends on the model, microphone and language;
passing execution checks does not mean perfect transcription accuracy.
