# AILIS v1.4.3

## Managed AILIS Cloud

- AILIS Cloud is ready on first launch without a user API key.
- The managed endpoint, upstream model, protocol, request parameters and vision
  routing are owned by AILIS and no longer exposed as editable user settings.
- Stored or imported server profiles cannot override the official AILIS Cloud
  endpoint or model. Direct-provider and local Ollama profiles remain editable
  and keep their independent history.
- Fixes the Agent Runner preflight that incorrectly rejected AILIS Cloud when
  no user API key was present.

## First-Launch Experience

- Uses the current AILIS character scale and bright companion MToon rendering
  profile for new installations.
- Aligns the initial camera, lighting, outline and 30 FPS render settings with
  the current desktop experience.
- Enables AILIS hosted voice and fast VAD recognition by default.
- Existing users keep their direct-provider or local-model selection and other
  saved preferences. Managed AILIS Cloud internals are normalized automatically.

## Downloads

- `AILIS-Setup-1.4.3-win-x64.exe`: Windows x64 installer with installation-path selection.
- `AILIS-Portable-1.4.3-win-x64.exe`: Windows x64 portable edition.
- `SHA256SUMS.txt`: integrity hashes for the release artifacts.

The lightweight release does not bundle Unity/AIGAME, local model weights or
large offline voice runtimes. The Windows binaries are not Authenticode-signed,
so Windows may display a publisher or SmartScreen warning.
