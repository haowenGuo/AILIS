# AILIS v1.4.5

## Managed server hotfix

- Made AILIS Cloud the Agent Runner's own default configuration when an entry point omits `llmSettings`.
- Kept direct API, local model, and explicit provider settings unchanged when they are supplied.
- Removed the remaining dependency on every caller correctly injecting the managed provider before the Agent Loop starts.

## Release verification

- Added a packaged clean-machine Agent-turn gate.
- The gate isolates `APPDATA`, `LOCALAPPDATA`, `USERPROFILE`, `HOME`, `TEMP`, Electron `userData`, and removes model-related environment variables.
- It launches the installed application, enters through the real Electron IPC and Gateway path, sends a random validation prompt to AILIS Cloud, and requires a non-empty model response without `needs_llm_config`.
- Installer launch, portable launch, checksums, offline package closure, default provider state, and uninstall remain part of the release gate.

## Packages

- `AILIS-Setup-1.4.5-win-x64.exe`: Windows x64 installer.
- `AILIS-Portable-1.4.5-win-x64.exe`: Windows x64 portable edition.
