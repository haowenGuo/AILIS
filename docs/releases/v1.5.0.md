# AILIS v1.5.0

## 正式发布

v1.5.0 将此前的 `1.4.9-memory.1` 层级用户记忆候选转为正式 AILIS 版本，使用普通 AILIS 应用身份、普通安装包命名和普通用户数据目录。原 `1.4.9-memory.1` 试用版分支与试用数据目录保留，不作为正式升级包的身份依据。

## 包含内容

- 层级用户记忆：从有效会话压缩摘要建立第 0 层节点，并在达到阈值后递归归并。
- 512K 上下文窗口、既有语义压缩、模型传输恢复、图片输入和工具链修复继续保留。
- 用户/租户隔离、节点归档、重启恢复和失败归并重试。
- 正常 AILIS 桌面应用身份：`com.ailis.desktop`，产品名 `AILIS`。

## 发布前证据

- 记忆单元测试：49/49 通过。
- 固定十题双臂门禁：20/20 trials 完成，baseline 2/10，candidate 3/10。
- 整题 pass-to-fail：0。
- 真实模型 canary：修正、归并、物理 worker handoff、重启恢复、SSE 会话和租户隔离通过。
- 正式发布源：`release/v1.5.0-memory-trail`。

## 已知限制

固定门禁中 KV 长连接/存活性子检查出现 baseline 通过、candidate 失败；这是已记录并接受的发布风险，不是“全部检查通过”。自然长程的 512K 压缩质量、长期个人记忆收益和其他平台安装包仍需单独验证。

## 回退

回退应恢复到 v1.4.9 的正式发布源，并保留 v1.5.0 的用户数据备份；不能直接覆盖用户会话目录，也不能把试用版目录误当成正式版目录。
