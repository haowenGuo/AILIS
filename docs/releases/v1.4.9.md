# AILIS v1.4.9

## 更新内容

- 修复 GPT-6 Luna 未匹配 A7 大窗口配置的问题：默认窗口 272,000 Token，预警 220,000，压缩触发点 244,800，紧急阈值 258,400。
- 未配置窗口的未知模型，兜底窗口由 128,000 提升到 256,000 Token。显式设置、接口能力声明及环境配置仍优先，包括小窗口模型；兜底压缩比例保持不变。
- README 新增 [ALE 同模型成绩与资源对照](../evaluation-ale-20261012.md)：98 道有效同题，AILIS 49.35%、Codex 48.53%，统一 GPT-6 Luna / xhigh。包含逐题分数与完整 Token 统计。

本次是 v1.4.8 上的窄范围窗口修复，不更换提示词、工具、模型、推理档位或压缩算法，不引入未发布的界面、服务端业务或评测实验。ALE 成绩来自窗口修正前的冻结运行，本版没有重新评测。

## 安装包与验证

支持 Windows x64、Linux x64、macOS Intel x64 和 Apple Silicon arm64。四个平台使用同一提交构建；发布附件包含源码身份、SHA256、冷环境工具执行和离线 ASR 验收证据。Windows 另运行 NSIS 安装、新配置 Agent 对话、启动和卸载验收。

完整 Whisper Small 与私有 CPU 推理环境继续随包提供；远端模型和 TTS 需要联网。Windows 未作可信发布者签名；macOS 使用 ad-hoc 签名、未作 Apple 公证，要求 macOS 14 或以上。Linux 验收覆盖原生构建及 TAR 重定位，不代表所有发行版的桌面与麦克风环境。

v1.4.8 的标签和安装包保留，可用于回退。服务器端只部署相同的窗口配置补丁，不更换模型中转、账号、支付或数据库。
