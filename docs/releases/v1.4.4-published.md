## 验收与限制

原生 runner：Windows Server 2025、Ubuntu 22.04、macOS 15 Intel、macOS 14 ARM。各平台 22 项最终包执行测试通过，核验 11 个关键源码文件及全部随包运行时文件哈希。覆盖最小 PATH、空配置、shell/PTY、EXEC、apply_patch、工作目录错误、离线 CPU ASR。Windows 另通过 25 项实际安装、首启、便携版和卸载检查。Mac ZIP/Linux tar 解压到中文空格新路径后再次验证。

两条合成中文样例：第一条归一化后 0/14 字错；第二条有 1/18 同音字错误（“文件夹”→“文件加”）；静音测试通过。可运行性不等于广泛识别质量评测。

没有 Windows 发布者证书或 Apple Developer ID/公证，Mac 为 ad-hoc 签名。系统可能显示 SmartScreen/Gatekeeper 提示，请勿关闭系统全局安全保护。麦克风等权限仍需用户授权。

尚未全面验证真实麦克风、所有硬件/CPU、桌面权限、付费模型请求；Linux DEB 安装/卸载、AppImage GUI 以及 Mac DMG 拖拽/Gatekeeper 体验未单独实测。CI 的最小环境检查不等于每种裸机都已验证。

完整验收 JSON/日志在各平台 `acceptance-*.tar.gz`。更新元数据保留每架构原始清单并提供合并 `latest-mac.yml`；安装包本体未重建、未混用历史 run。
