# AILIS v1.4.7

本版同步桌面任务交互、语音体验与当前网站服务。

## 更新内容

- 自动 ASR 支持唤醒词选择，保留手动录音；完整 Whisper Small 和私有推理环境继续随安装包提供。
- 改进 Markdown、任务文件与 HTML 预览的展示。
- 改进记忆整理的历史读取和有界重放，保留统一 Session 执行链路。
- 明确呈现当前执行权限；模型接口错误停止本轮，避免无效请求持续空转。
- 改进角色口语回复及语音诊断；默认模型与远端语音均连接当前 AILIS 服务器。
- 同步账号、会员订单和微信/支付宝协议修复。支付仍未开放，不会因升级自动收费。

## 安装与发布

Windows x64、Linux x64、macOS Intel x64 和 Apple Silicon arm64 沿用原生构建与安装验收。
安装包包含本地 ASR；模型服务和远端 TTS 仍需联网。Windows 未作发布者签名，macOS 未作 Apple 公证。

正式下载以 GitHub Release 随附的源码提交、SHA256 校验和及各平台验收报告为准。
本版不包含未启用的原生沙箱实验、开发机用户配置、聊天记录或访问凭据。
