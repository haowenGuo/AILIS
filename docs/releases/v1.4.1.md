# AILIS v1.4.1

2026-09-04 · Windows x64 · [Releases](https://github.com/haowenGuo/AILIS/releases/tag/v1.4.1)

## 中文

### 本版变化

- 整合 `07c1e85` 的上下文基线：稳定的追加式历史、独立 Persona 上下文，以及 code-mode 工具执行与结果投影。
- code-mode 中的嵌套工具继续经过普通工具的权限、审批和审计路径；支持执行与续取结果。
- 整合自 v1.4.0 以来的辅助视觉路由、多模态 TaskAgent 和 Web 语音输入修复。
- 修复语义压缩回退路径丢失 developer 角色附件上下文的问题，同时兼容旧 user 角色记录。
- 修复韩语语音配置被归一化为其他语言的问题。
- 发布测试扩展到上下文、工具运行时及配置兼容；安装包清单记录源码提交和工作区是否有未提交改动。

### 下载与升级

使用 `AILIS-Setup-1.4.1-win-x64.exe` 安装，或下载 `AILIS-Portable-1.4.1-win-x64.exe`。本版为轻量核心包，大型本地语音、ASR 和其他运行时仍为可选组件。下载后可用 `SHA256SUMS.txt` 校验文件。

升级前结束正在运行的任务，退出 AILIS，并备份 `%APPDATA%\AILIS`。不要删除用户数据；备份可能含聊天和 API 凭据，勿上传。旧会话会保留，但建议使用新会话观察新版上下文行为。回退时保留当前数据副本，再使用旧安装包及升级前备份。

### 已知边界

本版安装包未做 Authenticode 签名。缓存命中率取决于模型服务、缓存有效期和请求前缀，不能保证固定费用降幅。本次发布不包含新的完整 GAIA/Terminal-Bench 成绩；文档中的历史分数仍属于各自冻结源码，不得归属于 v1.4.1。

## English

This release integrates the context baseline from `07c1e85`: stable append-only history, a separate Persona context store, and governed code-mode tool execution/result projection. Nested tools keep the normal permission, approval, and audit path. It also includes the auxiliary-vision, multimodal TaskAgent, and web speech-input changes made since v1.4.0.

Two compatibility fixes preserve developer-role attachment context during fallback semantic compaction (including legacy user-role envelopes) and retain Korean voice-profile language settings. Release regression coverage now includes these paths, and release manifests record source commit and dirty-worktree status.

Download the Windows x64 Setup or Portable package and verify it against `SHA256SUMS.txt`. Large voice/ASR/runtime packs remain optional. Finish active tasks and exit AILIS before upgrading; back up `%APPDATA%\AILIS` and keep it private because it may contain conversations and API credentials. Start a new conversation to assess the new context behavior. Keep the previous installer and pre-upgrade data backup for rollback.

The binaries are not Authenticode-signed. Cache efficiency depends on the provider, cache lifetime, and request prefix; this release promises no fixed cost reduction. No new full GAIA or Terminal-Bench result is claimed. Historical benchmark evidence retains its original source identity.
