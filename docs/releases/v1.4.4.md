# AILIS v1.4.4

## Managed Server Activation

- Fixes AILIS Server mode on upgraded installations and other computers that
  still had an incomplete direct-provider profile saved locally.
- Selecting AILIS Server now activates and persists the managed connection
  immediately; users do not need to enter an API Base, model ID or API key.
- Agent and Agent Lab requests normalize managed-server settings in the main
  process, so stale renderer payloads cannot restore an invalid local profile.
- Direct-provider and local Ollama settings remain separate and unchanged.

## Verification

- Control-panel managed-server activation smoke test passed against source and
  the production renderer bundle.
- Agent Runner, connection-profile and render-profile regression suites passed.
- The lightweight Stockfish runtime is now explicitly included in packaged
  builds and verified by the offline production-package probe.
- Windows x64 installer and portable package were built from a clean release
  worktree based on the published v1.4.3 commit.

## Downloads

- `AILIS-Setup-1.4.4-win-x64.exe`: Windows x64 installer with installation-path selection.
- `AILIS-Portable-1.4.4-win-x64.exe`: Windows x64 portable edition.
- `SHA256SUMS.txt`: integrity hashes for the release artifacts.

The lightweight release does not bundle Unity/AIGAME, local model weights or
large offline voice runtimes. The Windows binaries are not Authenticode-signed,
so Windows may display a publisher or SmartScreen warning.
