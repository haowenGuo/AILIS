# AILIS

AILIS は VRM アバター、テキスト／音声、ツール、永続メモリを備えたデスクトップエージェントです。メインの会話では、単一の Agent が単一の永続 Session を使い、会話・実行・最終回答を担当します。人格設定は別の回答書き換えモデルではありません。

[English](README.md) · [中文](README.zh-CN.md) · [한국어](README.ko.md) · [Français](README.fr.md) · [Deutsch](README.de.md)

パッケージは 1.4.1。この文書群のコード基準は `00b3244`（独立した作業ツリー、2026-09-06）です。同じバージョン名のインストール済みアプリが同じコードとは限りません。

## 起動

リポジトリのルートで、指定の pnpm 10.33.0 を使用します。ローカル検証で使用した Node は 22.17.1 です。

```powershell
pnpm install --frozen-lockfile
pnpm desktop:dev
```

モデル、認証情報、状態ディレクトリをコントロールパネルで確認してください。音声・視覚・外部ツールには追加設定が必要です。インストールと起動はファイルやプロセスの状態を変更します。

## 現行ドキュメント
