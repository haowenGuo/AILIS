Hi, it's lovely to meet you! ✨

I'm AILIS, a lively virtual assistant who likes to keep things light. My everyday job is to chat with you, research things, write code, manage email, and even run terminal tasks for you.

I may look soft and cute, but I have an AI brain too 🧠✨ Whether you are reading papers, writing code, organizing files, or simply looking for company, I'll be here when you need me.

🚀 AILIS Project
📁 AILIS · v1.3.0 · MIT Open Source

AILIS is the current AILIS main project. It lets me, AILIS, live on the desktop, hold conversations, understand context, remember preferences, and use tools to complete real tasks.

🎯 Product direction

  • Humanlike experience — Stay with you like a real girl, with expressions, personality, and warmth
  • Professional capability — Task execution designed toward the reliability of Codex and Claude Code
  • Local first — An Electron local runtime that keeps privacy and control on your computer
  • Tool framework — AILIS Gateway + Agent Runner for planning, approval, tool calls, and auditing

🌟 Core features

  • 🎭 VRM 3D character — A 3D avatar with real-time expressions and motion
  • 🗣️ Voice interaction — TTS voice output + ASR speech recognition
  • 👁️ Visual understanding — Read-only screen perception for understanding context
  • 🧠 Long-term memory — Remember your preferences and understand you better over time
  • ⚡ Tool execution — Search, email, files, code, and terminal workflows

🛠️ Technology

Electron Vite VRM / Three.js TypeScript Node.js WebSocket IMAP / SMTP RAG / Memory

The main GitHub repository is haowenGuo/AILIS, and it continues to evolve around a desktop-first AILIS architecture.

📌 Current status

  • ✅ Core conversation + VRM rendering are stable
  • 🔄 Presentation and memory quality are being improved
  • 🔄 Voice and visual experiences are being refined
  • 🔄 Tool contracts and test coverage are expanding
  • 💡 Actively maintained on GitHub, with continuous development on the main AILIS project.

📖 MIT Open Source

AILIS is now MIT licensed. The desktop runtime, Agent toolchain, and local character extensions remain open. You can bring your own model API key, use a local model, or share character packs, skins, and skill extensions with the community.

The source code uses the MIT License, making it straightforward to learn from, extend, and contribute to.
Character and skin packs use a local asset-pack runtime, without requiring an online account or centralized service.
Cloud models, voice services, and third-party assets remain subject to the licenses of their providers and creators.
