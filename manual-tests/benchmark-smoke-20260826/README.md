# 文件任务样例

本目录保存用于手工检查文件处理能力的输入：

| 文件 | 用途 |
| --- | --- |
| [最高温度 CSV](terminal-02-temperatures/daily_temp_sf_high.csv) | 日期与温度统计 |
| [最低温度 CSV](terminal-02-temperatures/daily_temp_sf_low.csv) | 多表读取与比较 |
| [访问日志](terminal-03-access-log/access_log) | 文本解析和聚合 |

将输入复制到专用测试目录，为每次任务明确输出文件和验收条件。保留实际程序身份、请求、工具结果和产物，再独立核对计算结果。

这些是手工样例，不提供正式数据集评分。测量与报告方法见[运行观测](../../docs/engineering/measurement.md)。
